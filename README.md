# Sokol Chess

Шахматы против собственного движка **Sokol** с оценкой ходов как на chess.com. Есть версия для Windows и для Android, движок у них один и тот же.

## Установка

Готовые файлы лежат в разделе **Releases** этого репозитория.

- **Windows:** скачайте `SokolChess.exe` и запустите двойным щелчком. Устанавливать ничего не нужно: используется .NET Framework 4.8, который уже встроен в Windows 10/11.
- **Android (7.0 и новее):** скачайте `SokolChess.apk` на телефон, откройте его и разрешите установку из этого источника («Установка неизвестных приложений»). APK подписан стандартным отладочным ключом, поэтому Play Защита может предупредить о неизвестном разработчике.

## Возможности

- **Бот Sokol, ELO от 200 до 3500** (шаг 50). Слабые уровни ищут неглубоко и иногда ошибаются «по-человечески», сильные считают глубже, на 2800+ играют в полную силу и думают дольше (0,5–3,5 с на ход).
- **Только легальные ходы**: проверяются шах, связки, рокировка, взятие на проходе и превращение пешки (с выбором фигуры). Партия завершается матом, патом, троекратным повторением, правилом 50 ходов или нехваткой материала.
- **Оценка каждого хода** движком на полной силе: Блестящий (!!), Отличный (!), Лучший, Превосходно, Хороший, Теория, Неточность (?!), Ошибка (?), Промах, Зевок (??), Вынужденный. Зелёная стрелка показывает лучший ход, в карточке — объяснение (что теряется, какой ответ у соперника, лучшее продолжение).
- **Анализ партии** после игры: точность обоих игроков, количество ходов каждой категории, график оценки, переход по ходам.
- **Запись ходов** в вашей нотации: пешка без буквы (`h3`), фигуры с буквой: `R` ладья, `B` слон, `K` конь, `Q` ферзь, `K^` король. Можно переключить на международную (N, K) или русскую (К, С, Л, Ф, Кр).
- Подсказка, отмена хода, поворот доски, шкала оценки, звук, дебютная книга с названиями дебютов, PGN (копирование на Windows, «Поделиться» на Android).
- Windows: горячие клавиши ← → Home End (ходы), H (подсказка), Ctrl+Z (отмена), F (поворот).
- Android: ход касанием или перетаскиванием (фигура поднимается над пальцем), настройки и новая игра — кнопка «Игра» или значок ELO вверху; незаконченная партия сохраняется при сворачивании.

## Сборка из исходников

**Windows** — нужен Visual Studio 2022 (компилятор C#):

```
powershell -ExecutionPolicy Bypass -File build.ps1          # SokolChess.exe
powershell -ExecutionPolicy Bypass -File build.ps1 -Tests   # tests\bin\EngineTests.exe (perft, тактика, матчи уровней)
```

**Android** — нужны .NET 8 SDK с workload `android`, Android SDK и JDK (подойдёт JBR из Android Studio):

```
cd android
dotnet publish SokolChess.Android.csproj -c Release -f net8.0-android -p:AndroidSdkDirectory=%LOCALAPPDATA%\Android\Sdk "-p:JavaSdkDirectory=C:\Program Files\Android\Android Studio\jbr" -p:LatestSupportedJavaVersion=21.0.99
```

Готовый APK: `android/bin/Release/net8.0-android/publish/com.sokol.chess-Signed.apk`. Параметр `LatestSupportedJavaVersion` нужен, если установлен JDK 21 (сборщик .NET 8 официально ждёт JDK 17).

## Устройство проекта

- `src/Engine` — движок: битборды с magic-таблицами, генерация ходов, альфа-бета (PVS) с итеративным углублением, таблицей транспозиций, нулевым ходом, LMR, оценкой PeSTO, дебютной книгой, уровнями силы и классификацией ходов.
- `src/Shared` — общее для обеих платформ: модель партии, фоновый анализ, синтез звуков.
- `src/App` — интерфейс Windows (WinForms).
- `android` — интерфейс Android (.NET for Android), подключает `src/Engine` и `src/Shared` без копирования.
- `tests` — perft, тактика, нотация, классификация, матчи уровней.

ELO уровней ориентировочное: уровни проверены матчами друг против друга (каждый следующий уверенно сильнее предыдущего), а не против людей. На максимуме это сильный любительский движок, но не настоящие 3500 — до Stockfish ему далеко.
